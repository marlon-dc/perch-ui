# Colors

Color is a set of CSS custom properties (`--pu-*`) declared once for light and once for dark. Tailwind's
theme points at the same variables, so `bg-surface`, `text-muted` and `border-line-strong` switch with
the theme automatically. The "soft and warm" direction pairs paper-toned neutrals with a deep green accent.

## Rules of use

- Text is at least 4.5:1 against its background. Control borders, focus rings and meaningful icons are at least 3:1.
- `line` is decorative (dividers) and has no contrast requirement. Anything that marks a control's edge uses `line-strong`.
- Color is never the only signal: done rows and table cells also carry a check and hidden "Done" text, and negative numbers also carry a minus sign (U+2212).
