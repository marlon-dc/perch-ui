# Typography

Two typefaces, both self-hosted through `@fontsource`:

- **Plus Jakarta Sans** (400, 500, 600, 700) for UI text, utility `font-ui`.
- **JetBrains Mono** (400, 500, 600) for numbers and money, utility `font-num`, always with `font-variant-numeric: tabular-nums` so columns of figures line up.

## Headings

<div className="flex flex-col gap-3 rounded-2xl border border-line bg-surface p-4">

## Money

`Money` renders in the mono face with tabular figures. The default currency is the peso (`en-PH`); both are configurable. Negative amounts use a true minus sign (U+2212), not a hyphen.

<div className="flex flex-col gap-2 rounded-2xl border border-line bg-surface p-4">
  <Money amount={12000} symbol size="xl" />
  <Money amount={2450.5} symbol />
  <Money amount={-1800} symbol colored />
  <Money amount={5000} symbol colored />
  <Money amount={1234.5} currency="USD" locale="en-US" symbol />
</div>

```tsx
<Money amount={-1800} symbol colored />;
formatMoney(12000, { symbol: true }); // "₱12,000.00"
```
